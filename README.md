# Subsea Pump Performance Monitor
Built for the Digital Operations Process Engineer role at OneSubsea.
Objective: This tool simulates real-time monitoring of subsea pumps, identifies a performance deviation (pressure drop), and visualizes the fault using Python (Pandas, Matplotlib).
Output (Dashboard): Pump Performance Dashboard (pump_dashboard.png)
The top chart shows the pressure drop over time (highlighted in red). The bottom chart shows the Flow vs. Pressure curve, clearly separating normal operation from the fault condition.
